# Model run decision

No new model run is justified by this audit. The inspected corrected v1/v2/v3 temporal runners and the controlled v4/v5 artifacts construct features only from keyed prior-year rows or strict district histories ending at t-1. The contemporaneous target-component pathway is confined to the random-split observed-year notebook experiment. The forecast feature contract and saved lineage support this distinction.

A new run is not required merely to restate the existing corrected experiments. Current saved v4/v5 results are the corrected temporal outputs; they are not retrained here. The remaining operational forecast-origin/release-date gap cannot be repaired by retraining. Same-year notebook scores remain diagnostic observed-year classification only.

The proposed deployment scenario is a one-year-ahead annual forecast issued immediately after the preceding year's NCRB outcome becomes available. It is a scenario definition, not evidence that the input would in fact have been available then. Obtain NCRB release/access records before making operational forecasting claims.
